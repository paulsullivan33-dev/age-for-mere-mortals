The lab — one real install, one machine, its own keys only
================================================================

The lab is age as its author ships it: the official release
archive age-v1.3.2-linux-amd64.tar.gz, unpacked into a folder
on the build machine (a small Ubuntu Linux sandbox). The
machine's package sources did not carry age, so no package
manager was involved; the tools ran from their folder.

  * age, age-keygen and age-inspect, all version 1.3.2.
  * The release folder also carried age-plugin-batchpass,
    age-plugin-tag and age-plugin-pq (listed in t00, not
    exercised as end-user tools).
  * Every key pair was generated by the lab, for the lab,
    and is printed in full in the transcripts. They guard
    nothing. Never do this with a real key.
  * Two plain-text fixtures, both invented for the guide:
    a one-line note.txt ("The backup drive lives in the
    blue box on the shelf.") and a two-line rota.txt with
    invented names. Three further key pairs (Bob, Carol,
    and a post-quantum pair) and one throwaway SSH Ed25519
    pair were made as the chapters needed them; two of them
    "play" rota team members in the transcripts.
  * Passphrase runs needed a terminal (age insists on one
    for -p), so the lab drove them through a pty using the
    standard `script` utility. The lab passphrase was
    "sunny-day-42", chosen to be printed here; the wrong
    one tried against it was "rainy-day-99".
  * The lab's one self-correction is recorded in t13:
    an early draft claimed age refuses to overwrite an
    existing -o target. It does not. The text now says so,
    with the transcript as evidence.

available; chapter 12 labels that half documented-only),
RSA SSH keys, and any other machine than this one.
